# CS 549 Learning for Robotics: interactive demonstrations

Browser demonstrations and recordings that the CS 549 slides link to. They are published at
https://oz-oguz.github.io/cs549-demos/ . The slides themselves are in https://oz-oguz.github.io/cs549-materials/ .

- `statics-and-grasp-selection/`: statics and grasp selection (forces and wrenches, friction cones, force allocation, antipodal grasps,
  perception to grasp, and recorded Drake simulations).

This repository keeps no history: every publication replaces the previous version, so links into it always open
the current demonstration. The addresses the slides use stay valid across updates.
